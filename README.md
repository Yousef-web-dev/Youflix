# 🎬 Youflix - Ultimate Movie & Streaming Platform

A modern, full-featured movie and TV show streaming web application built with **Next.js (App Router)**, **Tailwind CSS**, and **Framer Motion**, delivering an immersive, Netflix-inspired user experience.

---

## ✨ Key Features

- **Immersive Dark UI:** Styled specifically for a cinematic look and feel, inspired by top streaming platforms like Netflix.
- **Dynamic Content Browsing:** Explore trending movies, TV shows, genres, and detailed metadata powered by the TMDB API.
- **In-App Video Playback Modal:** Seamlessly watch official trailers directly inside the application using an interactive modal player (no annoying external tab redirects).
- **My List System:** Add and manage your favorite movies and series locally with instant UI updates.
- **Advanced Search & Performance:** Fast navigation and optimized routing leveraging Next.js App Router and Turbopack.
- **Fully Responsive:** Optimized for seamless viewing across desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://gsap.com/) & [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Data Source:** [TMDB API](https://www.themoviedb.org/)
- **Deployment:** [Vercel](https://vercel.com/)
